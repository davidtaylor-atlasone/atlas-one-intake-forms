1. `#main` has NO CSS at all. Grep `#main` in build_command.py returns nothing. That, not the missing
   `min-height:0`, is the root cause of the scroll bug: `body` is the flex column, `#content` sets
   `flex:1;overflow:auto`, but `<div id="main">` sits between them as an unstyled block, so `#content` is
   never a flex child of anything and never becomes a scroll container. `body{overflow:hidden}` then clips
   everything past the first screen. Both fixes are needed, not one.

   exactly David's "the list stays filtered and clearing the box does not restore the page".
3. `run()`'s empty term branch never sets `searchheading.hidden = true`, so the "Search results" heading
   stays on screen after the box is cleared.
4. `INTERNAL_PASSPHRASE = "atlas1"` is at build_command.py line 110 and is written into the built HTML in
